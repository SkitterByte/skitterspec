## Notes

**Version bump is deferred to the release step, not hand-edited here.** This repo
cuts versions with its release tooling (`scripts/release.js` → generated
`CHANGELOG.md` / `RELEASES.md` from commit footers), so hand-editing
`package.json` would desync the changelog. The breaking `feat(sync)!` commits
already drive `skitterspec-linear` to **9.0.0**; the base `skitterspec` also
gains the `Name` handle (a `feat`), so it takes a **minor** (15.1.0) at the same
cut. The user-facing `Release-Note!` lands on the Phase 4 commit. The title fix
(`1d0d301`) rides in too. Actual `npm version` + publish happen at
`/spec-complete` / release time.

The composed `packages/skitterspec*/assets` and `…/src/vendor` are gitignored
build outputs — regenerated by `build-dist`, never committed.
